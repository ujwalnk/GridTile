# Security Policy

## Supported Versions

Currently, only the latest version of GridTile is supported with security updates.

| Version | Supported |
| ------- | --------- |
| Latest  | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability in GridTile, please report it privately rather than opening a public issue.

You can report vulnerabilities by opening a private security advisory through the repository's **Security** tab.

Please include as much detail as possible, including steps to reproduce the issue and any relevant screenshots or logs.

We will review reported vulnerabilities and provide an update as soon as reasonably possible. If the vulnerability is confirmed, we will work on a fix and release an updated version where appropriate.
